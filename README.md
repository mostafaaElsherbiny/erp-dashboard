# ERP Dashboard

> **Note:** This repository is used as part of my mentor program.

A full-stack, technology-agnostic Enterprise Resource Planning dashboard. Choose a frontend, backend, and database stack that fits your implementation; the project is organized into three progressive levels, starting with the core ERP foundation in [LEVEL1.md](LEVEL1.md).

## Guides

| Guide | Contents |
|-------|----------|
| [Level 1: ERP Foundation](LEVEL1.md) | Technology options, project structure, setup instructions, users and roles, customers, inventory, purchasing, sales, finance, HR, and the core database schema. |
| [Level 2: Secure Project Operations](LEVEL2.md) | Projects, tasks, comments, CRUD APIs, JWT authentication and authorization, acceptance criteria, and schema additions. |
| [Level 3: Automation, Analytics & Integrations](LEVEL3.md) | Reports, workflow automation, notifications, audit history, webhooks, background processing, and security requirements. |

## Implementation Order

1. Complete the [Level 1 guide](LEVEL1.md) to establish the ERP foundation.
2. Extend it with the [Level 2 guide](LEVEL2.md), keeping existing routes and response contracts compatible.
3. Add the [Level 3 guide](LEVEL3.md) for analytics, automation, and integrations after Levels 1 and 2 are stable.

All levels are technology-agnostic. Choose one frontend, backend, and database stack and use it consistently across the project.
