# ERP Dashboard

A framework-agnostic ERP dashboard project organized into two implementation levels.

## Guides

| Guide | Contents |
|-------|----------|
| [Level 1: ERP Foundation](LEVEL1.md) | Technology options, project structure, setup instructions, users and roles, customers, inventory, purchasing, sales, finance, HR, and the core database schema. |
| [Level 2: Secure Project Operations](LEVEL2.md) | Projects, tasks, comments, CRUD APIs, JWT authentication and authorization, acceptance criteria, and schema additions. |

## Implementation Order

1. Complete the [Level 1 guide](LEVEL1.md) to establish the ERP foundation.
2. Extend it with the [Level 2 guide](LEVEL2.md), keeping existing routes and response contracts compatible.

Both levels are technology-agnostic. Choose one frontend, backend, and database stack and use it consistently across the project.
